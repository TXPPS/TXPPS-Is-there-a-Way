# Is There a Way?

A first-person horror escape game for the phone. A decommissioned mid-century
lock-and-dam on the Mississippi seals itself with you below grade, and the
person who sealed you in believes he is doing you a kindness.

Built in **Godot 4.6.3** (Compatibility / WebGL2, single-threaded web export),
targeting **iPhone 16 Pro Max, Safari, landscape**. Everything ships as text —
`.tscn`, `.tres`, `.gd` — and every asset is generated by a script committed
here.

## Build it

```sh
# Fetch the pinned engine and just the Web export templates (~81 MB, not 1.26 GB)
python3 tools/ci/fetch_godot.py --version 4.6.3-stable --dest .godot-sdk

# Stamp, verify generated art, import, boot headless, export, harden, budget-check
GODOT="$PWD/.godot-sdk/godot" bash tools/ci/build_web.sh

# Drive the real export in a headless browser at iPhone landscape metrics
npm --prefix tools/web ci && node tools/web/smoke_web.js build build-smoke

# Serve it
python3 -m http.server 8000 --directory build
```

Opening the project in the Godot desktop editor needs nothing but the editor:
`godot --path .`
